# CV Bullet Point Generator (Google XYZ Formula)

Every blueprint ends with 3 CV bullet variants using:
**"Achieved [X] as measured by [Y], by doing [Z]"**

Example:
- *Designed and built a Hybrid RAG technical document search engine (BM25 + Qdrant) [Z] that improved context retrieval accuracy (Recall@5) by 28% over standard vector search [X] across a 1,000-query domain test set [Y].*

Rules:
- Every bullet needs a number. No number, no bullet.
- [Z] names the mechanism, not the tool list.
- [Y] names the test set or harness so the claim is verifiable.
- Max 30 words per bullet. Write in the configured output language.
